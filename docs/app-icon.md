# Ivertim 3D ikona

Originalni PNG: public/ivertim-3d.png. Windows ICO: public/ivertim-3d.ico (16, 24, 32, 48, 64, 128 i 256 px). Generisano ugrađenim image_gen alatom; ICO je tehnički konvertovan iz PNG-a. Nema izmjene loadera ili originalnog Ivertim znaka.

Prečicu sa ikonom pravi scripts/create-shortcut.ps1, a redovno pokretanje je obnavlja prema lokalnoj putanji. Ivertim 3D.lnk je lokalni fajl i ne ulazi u Git.

## Prompt

Create one polished square desktop application icon for Ivertim 3D. A single sculptural 3D sphere with a clearly readable geometric notch cut out of its upper right front quadrant, revealing smooth planar interior cut surfaces, like precision CAD solid subtraction. Solid warm walnut brown main surface (#805A3C), lighter walnut cut faces (#C8A27F, #DDC5AD), rich dark brown recess (#493221). Matte satin material, no wood grain. Pure white background, soft elliptical contact shadow immediately below the slightly hovering sphere. Centered large sphere fills about 78% of canvas width; generous safe margins, clean simple silhouette recognizable at 32px. Orthographic three-quarter product render, soft studio lighting from upper left, subtle rounded edges. No text, no letters, no atom or orbital rings, no extra objects, no border, no grid. Professional restrained premium desktop software icon. Output 1024x1024 square.
